# One Line of Earned Pride

An entry for the [make.fun bounty "One Line of Earned Pride"](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557).

## What this entry is

A single line of text (1 to 240 characters) that gives the reader a quiet,
earned moment of pride for someone in a scene — a small person doing something
hard, a long effort finally landing. No trophy, no podium, no graduation:
just an old man, three winters of failing, and one clean park.

## The line

> After three winters of failing the driving test, old Mr. Chen parallel-parked his late wife's car first try — and sat there a moment, hands still on the wheel.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it writes the line above to `/output/entry.txt`
(no network, no randomness, no environment reads).
